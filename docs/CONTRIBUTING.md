# Contributing

## Code of Conduct
Be respectful, constructive, and collaborative.

## Development Setup
1. `npm install`
2. `npm run dev`
3. `npm run test:run`

## Branch Naming
Use `type/short-description` (e.g., `feat/add-playwright-tests`).

## Commit Messages
Follow Conventional Commits (`feat:`, `fix:`, `ci:`, etc.).

## Pull Request Process
1. Create feature branch
2. Implement and test changes
3. Run checks locally
4. Open PR with summary + verification
5. Address review feedback

## Code Style
Use ESLint + Prettier and TypeScript strict-safe patterns.

## Testing Guidelines
- Add/update unit tests for logic changes
- Add E2E coverage for critical workflows
- Maintain coverage thresholds

## Documentation
Update README/docs for any developer workflow or architecture changes.
